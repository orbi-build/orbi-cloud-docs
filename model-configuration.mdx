You do not need to configure a model: deliveries use Orbi's platform model channel by default. That channel runs DeepSeek V4 Flash, and the **AI model** section of Settings shows it as **In use now: DeepSeek V4 Flash from Orbi**. Your code and prompts on that channel are sent to DeepSeek; for how DeepSeek handles them, including training and retention, see [DeepSeek's privacy policy](https://cdn.deepseek.com/policies/en-US/deepseek-privacy-policy.html). To use a different model, configure your own key as described below.

Try it free for 14 days; see [Limits and quotas](/limits-and-quotas) for the rules.

Configuring your own key (**BYOK**, bring your own key) adds your provider account as a model source. The platform allowance is used first; when it runs out, deliveries switch to your key. Admission rules are in [limits and quotas](/limits-and-quotas).

## When you should configure a key

| Situation | What to do |
|---|---|
| You just want it to work | Nothing. The platform channel is used automatically |
| You want to choose the model used after the platform allowance runs out | Configure BYOK. Your key takes over after the platform allowance is used up |
| You have hit the monthly token quota | Configure BYOK. Saving resumes delivery paused by the platform token cap; that cap does not apply to your key |

## Configure it

Click your avatar, choose **Settings**, and open the **AI model** section. The same page also contains message language and notifications. When your monthly allowance is exhausted, **Use your own API key** on the status page links to this section.

1. **Provider**: pick from the list. Selecting one fills in its address for you.
2. **Model**: choose from that provider's known models, or choose **Enter another model** and type a model ID that is not in the list.
3. **API key**: your key from that provider.

The address sits under **Advanced connection settings**, collapsed by default, in the field **Address (filled in automatically; you can edit it)**. Change it only if you use a proxy or a private gateway.

Click **Test connection** first if you want to check the combination. It sends a small request with what you entered and reports either **Connection successful** with the model and how long it took, or the provider's error. Then click **Save model configuration**.

Saving runs the same connection test before anything is stored. If the test fails, nothing is saved: the page shows the error, keeps what you entered and asks you to enter the API key again. A provider outside the built-in list cannot be tested this way and is saved as entered.

After a successful save the page confirms **Model configuration saved**. Saving takes effect for deliveries that start afterwards. If preparing the work environment had failed, saving retries it automatically.

## How your key is stored

Your API key is encrypted at rest and is only ever displayed back to you masked: the field label shows something like **API key (current: ••••1234)**, never the key itself. It is never written to logs.

Do not send your key over email or paste it into a GitHub Issue, pull request or comment. Enter it on this page; that is the only channel you need.

## Using a provider that is not listed

Choose any provider as a starting point, then open **Advanced connection settings**, change **Address** to your gateway's URL, and type the model ID with **Enter another model**. Any OpenAI-compatible endpoint works. Saving still tests the connection against the URL you entered. Your configuration is stored as you entered it and shown back to you unchanged.

A saved provider that is not in the built-in list, is shown with **(not in the built-in list; saved as entered)**, and a saved model that is not in the provider's list is shown with **(saved)**.

## Removing your key

The **AI model** section has no delete button. To go back to the platform channel only, [contact support](/troubleshooting#getting-help) and ask for your key to be removed. To switch to a different key, just save the new one over it.

## What changes when you use BYOK

| | Platform channel (default) | Your own key |
|---|---|---|
| Who pays for tokens | Included in your plan | You pay your provider |
| When it is used | While the platform allowance is available | After the platform allowance is used up |
| Monthly token allowance | See [limits and quotas](/limits-and-quotas) | Not applied to your key; task admission still follows [limits and quotas](/limits-and-quotas) |
| Model choice | Operated by Orbi | Yours |
| Usage shown on the status page | **Monthly AI usage**, against the current allowance | **Monthly AI usage (your API key)**, on its own line with no limit, once your key has been used |

See [limits and quotas](/limits-and-quotas) for how the quota is counted.
