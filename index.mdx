Orbi Cloud is a hosted runner that watches your GitHub repository and automatically converts labelled Issues into reviewed, tested, and merged pull requests. You interact entirely through GitHub — writing Issues, applying labels, and inspecting pull requests — while Orbi handles implementation, an independent review cycle, and the final merge. This documentation covers everything you need to connect a repository, dispatch work, understand the delivery lifecycle, and manage your account.

## How It Works

<Steps>
  <Step title="Sign In with GitHub">
    Visit [orbi.build/api/](https://orbi.build/api/) and click **Sign in with GitHub**. Orbi requests only the `user:email` OAuth scope — no access to your code at this stage.
  </Step>
  <Step title="Install the GitHub App">
    Click **Install GitHub App** on the status page. On GitHub's installation screen, select **Only select repositories** and choose the repository you want Orbi to manage.
  </Step>
  <Step title="Connect a Repository">
    Back on the status page, click **Connect repository**, choose your repository and base branch, and let provisioning complete. Provisioning typically takes one to two minutes.
  </Step>
  <Step title="Label an Issue ai-ready">
    Create a GitHub Issue describing the change you want made, then apply the `ai-ready` label. Orbi picks it up within five minutes and begins delivery.
  </Step>
</Steps>

## What Orbi Does

Once you label an Issue, Orbi takes full ownership of delivery: it implements the change, opens a pull request, and routes that PR to a completely separate AI session for review. The reviewer can request repairs, which Orbi applies before the PR is merged — all without any manual intervention on your part.
