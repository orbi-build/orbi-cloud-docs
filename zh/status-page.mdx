状态页在 **[orbi.build/api/](https://orbi.build/api/)**，你在这里看 Orbi 正在做什么、什么需要你、以及你用了多少。

页面按你要做的事排序，不按功能排。从上到下依次是：

1. **顶栏**：左边是 Orbi 的 logo 和「Orbi Cloud」（点它总能回到这里），右边是你的头像和账户菜单。
2. **标题和「最近更新」**：标题「Orbi Cloud 状态」下面有一行「最近更新」，写着最近上线的新功能和它的用法链接。
3. 「下一步」：现在在发生什么，以及你此刻该做的那一件事。
4. **项目概览**：每个已连接的项目一行。
5. 「任务记录」：所有任务，分在三个标签页里。
6. 「用量与设置」：用量、已连接的项目和版本，默认折叠，点开才显示。
7. **页脚**：求助入口，以及服务状态、隐私政策、服务条款和 GitHub。

## 下一步

「下一步」卡片是页面上最先要看的部分。它依次包含：

- 「开通进度」：七个上手步骤（见下文）。
- 一句**标题**：用一句话概括你账户当前的状态。
- 「需要你处理」 或 「提醒」：等你处理的事项和条数，每一项都带着处理它的按钮。没有东西需要你时这部分不出现，这是好消息。
- **你已有的 Issue**：连接仓库后、第一次交付完成之前，Orbi 会列出你仓库里还没交给它的 Issue（最多三个），写着「选一个已有的 Issue 交给 Orbi。」，每个带一个「让 Orbi 做这个」按钮。见[第一个 Issue](/zh/first-issue)。
- 「写需求」：说说你想改什么，Orbi 写成草稿，你确认后点「交给 Orbi 开始做」。见[写需求](/zh/write-a-requirement)。Orbi 做完了、在等更多任务时，旁边还有「去 GitHub 新建 Issue」。
- 「挑一个让 Orbi 试试」：做过交付之后，Orbi 空闲时出现，列出一个新手小任务和你还没交给 Orbi 的 Issue，每个都带「试试 →」。

### 标题

| 标题 | 含义 |
|---|---|
| 「先连接一个仓库」 | 还没有连接任何仓库 |
| 「Orbi 正在准备工作环境」 | 刚连接的仓库正在[准备工作环境](/zh/provisioning)，一般几分钟 |
| 「工作环境准备失败，Orbi 会自动重试」 | 准备工作环境因临时原因失败，Orbi 会自己重试 |
| 「工作环境准备失败（Orbi 这边的问题）」 | 平台侧故障，不需要你操作，见[准备工作环境](/zh/provisioning) |
| 「Orbi 在等你的第一个需求」 | 已就绪。用「让 Orbi 做这个」交一个已有的 Issue，或者用「写需求」 |
| 「Orbi 正在写代码」 | 有一个任务正在做 |
| 「有任务在等别的任务先完成」 | 有任务在排队，要等它依赖的 Issue 先完成 |
| 「有任务等了 10 分钟以上还没开始」 | 有任务交给 Orbi 超过 10 分钟还没被认领 |
| 「有任务不在当前版本里，暂时不会做」 | 有任务不在当前版本里，Orbi 暂时不会做（免费账户显示为「有任务暂时不会做」） |
| 「Orbi 正在检查改动 #N，通过后自动合并到项目」 | 独立检查正在进行 |
| 「需要你在 GitHub 上批准这次改动」 | 分支保护要求合并前有人批准，见[分支保护](/zh/connect-repository) |
| 「Orbi 需要你确认一下」 | 有一个结果在等人确认 |
| 「Orbi 卡住了，需要你看一下」 | 有任务卡住，或者你那边有东西要修；「需要你处理」下面的那一项会说清是哪个 |
| 「Orbi 已完成，等你的下一个需求」 | 所有任务都做完了，Orbi 在等下一个 |
| 「暂时读不到 Orbi 的状态」 | Orbi 此刻读不到你的任务状态；卡片上会给出「刷新状态页」或「重新连接仓库」 |
| 「本月 AI 用量已用完，暂停接新任务」 | 付费账户本月的 AI 用量用完了，见下文 |

有两种情况会在「需要你处理」下面给出自己的出路：

- **免费次数用完**：卡片写着「免费的 3 次已用完：」，带一个「订阅」按钮。见[付费](/zh/billing)。
- **付费账户本月 AI 用量用完**：Orbi 暂停接新任务，进行中的照常做完。卡片提供「改用自己的 API key」，Solo 套餐还会提供升级到 Pro；也可以等到下月 1 日北京时间 8:00 用量重置后自动恢复。见[额度与限制](/zh/limits-and-quotas)。

### 开通进度

七个步骤跟踪上手过程：「登录」→「安装 GitHub App」→「连接仓库」→「准备工作环境」→「写第一个需求」→「建 Release」→「订阅」。做完的步骤标「已完成」；当前步骤会高亮，标「等你」「Orbi 处理中」或「失败」，并带一个「看这一步怎么做 ▶」链接，点开播放这一步的短视频。准备工作环境失败时，这一步旁边还有联系我们的入口。

轮到第 6 步「建 Release」时，它标「可以不做」，不做也不影响 Orbi 做任务。还在用免费次数的账户，最后一步显示为「前 3 次免费」，下面有一段折叠的「价格说明与账户」。必做的步骤都完成、并且有过一次交付之后，整个进度会折叠成「全部完成」。

## 项目概览

一张表，表头是「项目 N / 上限 M」，旁边有「管理项目」按钮，点它打开连接页，在那里添加或断开项目。每个已连接的项目一行，显示它有多少任务处于「进行中」「检查中」和「已完成」。需要注意的行会带一个标签：「需要你」「自动重试中」或「Orbi 这边的问题」。

有多个项目时，点某一行会打开这个项目自己的视图：它的基础分支、「在 GitHub 上查看」和「去 GitHub 新建 Issue」、「现在的状态」、它的「任务记录」，付费账户还有当前版本和「版本」。见[多个仓库](/zh/connect-repository)。

## 任务记录

你的任务分在三个标签页里，每个任务只出现在其中一个：

| 标签页 | 里面是什么 |
|---|---|
| 「进行中」 | 还没有 pull request 的未结束任务：排队中、正在写代码、在等补充信息，或在开 pull request 之前卡住 |
| 「检查中」 | 已经有 pull request 的未结束任务：正在过独立检查、正在按检查意见修改、在等你批准，或在开了 pull request 之后卡住 |
| 「已完成」 | 结束了的任务：已合并，或已关闭 |

表格的列是「任务」「状态」「改动」「更新时间」。「任务」链到 GitHub 上的 Issue，「改动」链到它的 pull request。任务上报用量之后，标题下方会显示一行用量：「用时」、「AI 调用」次数、token 总数（括号里分输入、输出、缓存），中途断过的还会显示「中断后继续」的次数。排队中的任务会注明「排队中，前一个完成后开始」，或者它在等哪些 Issue 先关闭。

「状态」列的标签对应[交付生命周期](/zh/delivery-lifecycle)里描述的那些 `ai-*` 标签：「排队中」「进行中」「Orbi 检查中」「按检查意见修改中」「等你批准」「待补充」「等你确认」「卡住」「已完成」「已关闭（未合并）」。打开 Issue，就能在 Orbi 的评论里看到原因和下一步。

## 用量与设置

默认折叠，点「用量与设置」展开。工作环境准备失败时它会自动展开，方便你直接看到原因。

<Frame caption="展开后的用量与设置：本月 AI 用量、已连接的项目和版本">
  <img src="/images/zh/status-settings.png" alt="展开后的用量与设置：本月 AI 用量、已连接的项目和版本" />
</Frame>

**本月 AI 用量**。「本月 AI 用量」一行显示本月已用的 token，以及「其中缓存」占的比例。付费账户还会显示套餐额度、「已用」百分比和「每月 1 日北京时间 8:00 重置」，下面一根进度条，到 80% 变琥珀色，到 100% 变红色。免费账户没有月度上限，只显示用了多少。配置了自己的 API key 后，用你自己的 key 跑的用量单独一行，显示为「本月 AI 用量（你的 API key）」。缓存读取和输入、输出一样计入额度，缓存占比不影响额度消耗的速度。见[额度与限制](/zh/limits-and-quotas)。

**已连接的项目**。每个项目和它的「基础分支」「准备状态」（「已就绪」「正在准备」或「准备失败」）；准备失败时还会显示「原因：」「时间：」「出错编号：」和「下一步：」。你断开过的项目列在折叠的「已断开的项目」下面。

<Frame caption="工作环境准备失败时，用量与设置自动展开，已连接的项目里写着原因、时间、出错编号和下一步">
  <img src="/images/zh/status-provision-failed.png" alt="工作环境准备失败时，用量与设置自动展开，已连接的项目里写着原因、时间、出错编号和下一步" />
</Frame>

**版本**。只有付费账户、并且只连接了一个项目时出现在这里。包括「当前版本：」、「未发布的版本」（每个版本带「切换到这个版本」，当前版本带「创建 Release 任务」或「查看 Release 任务」）、一个「新建版本」输入框和「新建并切换」按钮，以及一段折叠的「说明」。见[发版](/zh/releases)。

还在用免费次数的账户，第一次交付合并之后，这里还可能出现一段「创始会员优惠」。

## 账户菜单和页脚

订阅、「AI 模型设置」、语言、技术支持、这份文档和「退出登录」都在头像下的账户菜单里，见[账户菜单](/zh/sign-in)。

每个页面的页脚有两行。第一行是「需要帮助？」，后面是「Telegram 群」、「报告 bug（GitHub，公开）」和 support@orbi.build；第二行链到「服务状态」（服务状态页）、「隐私政策」、「服务条款」和「GitHub」。

## 刷新

工作环境正在准备的时候页面会自己刷新，那几分钟你可以把它开着不管。其他时候重新加载就能拿到当前状态。它实时读 GitHub，显示的是你 Issue 的真实状态，不是缓存副本。

如果 Orbi 此刻连不上 GitHub，页面会说「暂时读不到 Orbi 的状态」，不会给你一个误导人的空列表。
