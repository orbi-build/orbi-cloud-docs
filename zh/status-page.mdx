[状态页](https://orbi.build/api/)显示正在进行的交付、需要你处理的事、已连接项目和用量。账户设置在右上角头像菜单里，包含「AI 模型」「Orbi 消息语言」和「通知」。

## 下一步

主卡跟随当前工作变化。开通时显示当前步骤；交付中显示 Issue 和「写代码 → 检查 → 合并」、最近上报的动作，以及折叠的「最近进度」。进度上报说明会话最近在做什么；交付结果以 Issue 标签和 pull request 为准。

有事需要你处理时，主卡显示选中任务的原因和操作。还有其他待处理任务，就用「还有 N 张需要您处理」在同页切换。多项目总览还可能显示待处理总数。按当前票的提示批准 PR、补充需求、修正不存在的基础分支，或先读 Orbi 的卡住说明，见[排错](/zh/troubleshooting)。

### 标题

| 当前情况 | 怎么做 |
|---|---|
| 正在准备工作环境 | 等待，一般 10–20 秒；变慢或失败时看页面上的原因和帮助入口 |
| Orbi 正在读仓库 | 等建议，通常约 2 分钟；也可以自己写需求 |
| Orbi 在等第一个需求 | 查看建议草稿、交出已有 Issue，或点「写需求」 |
| 交付进行中 | 查看对应 Issue 和进度；新需求会排在它后面 |
| 需求待补充 | 点「补充需求」，更新原来的需求 |
| 改动需要批准 | 到 GitHub 打开对应 PR 并评审 |
| 任务卡住 | 先读原因并修复，再按[恢复规则](/zh/troubleshooting#ai-blocked)派发 |
| 免费次数或本月用量用完 | 按[额度与限制](/zh/limits-and-quotas)处理，进行中的任务不会被中断 |
| 暂时读不到任务状态 | 按页面提示刷新或重新登录；读不到不代表队列为空 |

项目空闲时，建议可能在主卡里；交付中则可以单独显示「Orbi 之前还建议了这几件」。「查看需求」先打开新任务草稿给你确认，「让 Orbi 做这个」立即派发已有 Issue。「为什么建议这件」展开建议的理由。

多个项目时，用「全部」或项目选择器筛选。「全部」先显示每个就绪项目的一条建议，展开后看其余建议。换一批前先选项目。见[第一张 Issue](/zh/first-issue)。

### 开通进度

现在只有**五步**：「登录 → 安装 GitHub App → 连接仓库 → 准备工作环境 → 写第一个需求」。交出第一个任务，第五步就完成，不需要等合并。发版和订阅是独立操作，不是额外的开通步骤。

安装 App、连接仓库和写第一个需求这三步有操作短片。准备工作环境时，进度会自动更新。

## 项目概览

「项目」区概括每个已连接项目当前在做什么；有交付时带出 Issue 编号和标题。「管理项目」进入仓库管理，并显示已用名额和套餐上限。官方示例副本单独列出，不占真实项目名额。

只有一个项目时，直接显示当前状态和任务记录。多个项目时，点项目行查看基础分支、当前版本、进度、任务记录和「版本」。多项目总览不会把所有项目的任务表混成一张。

公开项目的「README 徽章」可以展开预览，并复制 Markdown 放进 README。第一次合并后，「查看徽章」会提示这个入口。数字会自动更新，缓存约一小时；点徽章打开该项目的交付记录。状态页只给公开的真实项目提供入口，私有仓库和示例副本没有。

修改基础分支用「管理项目 → 改基础分支」，选择已有分支后保存。见[连接仓库](/zh/connect-repository#修改基础分支)。

## 任务记录

单项目的「任务记录」是列表，显示 Issue、状态和更新时间。先显示最近更新的三条，点「展开全部（N）」看其余记录，点「收起」折回。时间按浏览器的本地时区显示。

多项目账户选中项目后的详情仍使用三个标签页：

| 标签页 | 里面是什么 |
|---|---|
| 「进行中」 | 还没开 PR 的未结束任务：排队、写代码、待补充，或开 PR 前卡住 |
| 「检查中」 | 已有 PR 的未结束任务：检查、修改、等批准，或开 PR 后卡住 |
| 「已完成」 | 已合并或已关闭的任务 |

排队中的任务会说明在等什么，包括尚未关闭的前置 Issue。「查看进度」选中那张任务的进度。用量上报后，还能看到用时、AI 调用次数和输入、输出、缓存 token；中断过的任务可以显示接续次数。没有上报的用量不会当作零。

各状态对应的标签见[交付生命周期](/zh/delivery-lifecycle#每个标签的含义)。打开 Issue 看原因，打开 PR 看改动。任务记录读不到时，这一块会明确提示，不会把它说成从没做过任务。

## 用量与设置

展开「用量与设置」查看本月用量、已连接项目的准备状态和已断开的项目。准备工作环境失败时，这一块会展开，显示原因、时间、错误 ID 和修复操作。

「本月 AI 用量」显示平台 token 和缓存占比。付费账户还显示额度、已用百分比和重置时间：每月 1 日北京时间 08:00（UTC 00:00）。用量条在 80% 变黄，100% 变红。免费账户用一次性的交付次数，不是月度 token 额度。「本月 AI 用量（您的 API key）」另列自带 key 的用量。缓存 token 同样计入额度，见[额度与限制](/zh/limits-and-quotas)。

每个套餐都有「版本」入口：单项目在「用量与设置」里，多项目在选中项目的详情里。可以创建、切换版本，并发起发布任务，见[发版](/zh/releases)。

## 账户菜单与页脚

头像菜单里的「设置」管理模型 key、Orbi 消息语言和 [Telegram 通知](/zh/notifications)。菜单还提供订阅、网页语言、支持、文档和退出登录；具体项目随账户和订阅状态变化。

页脚提供 Telegram 支持群、备用邮箱和预约创始人 15 分钟的链接，以及服务状态、隐私、条款和 GitHub。支持群入口不会替你配置机器人通知。

## 手机上

手机上可以使用同样的操作。按需展开进度、任务记录和设置；选中的任务和它的操作显示在一起。

## 刷新

页面可见时，约每 **15 秒**读取一次交付状态。浏览器标签页隐藏时暂停，回来后立即读取。准备环境和读仓库也会自动更新。

没有权限或遇到限流时，进度读取会暂停，并提供「刷新进度」。登录过期需要重新登录。没有新的进度上报不代表成功或失败，当前结果仍看 Issue 和 PR。
