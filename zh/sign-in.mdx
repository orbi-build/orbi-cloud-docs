登录就是点一次 GitHub OAuth 确认你是谁，它本身不给 Orbi 任何仓库权限。

Orbi Cloud 没有自己的密码。你的 GitHub 账号就是你的身份，而仓库权限是另一个独立、明确的步骤 —— [安装 GitHub App](/zh/install-app) —— 这一步由你在 GitHub 上控制。

## 登录

打开 **[orbi.build/api/](https://orbi.build/api/)**，点 **使用 GitHub 登录** (Sign in with GitHub)。

<Frame caption="Orbi Cloud 登录页">
  <img src="/images/signin.png" alt="Orbi Cloud 登录页" />
</Frame>

GitHub 会给你它标准的授权页。批准之后你会回到 Orbi Cloud 状态页。

登录只申请一个 OAuth scope，`user:email` —— 你的身份和你的邮箱地址，仅此而已。它不会给出任何仓库的代码或 Issue 的访问权限。那些来自 GitHub App 的安装，单独授权，也单独列出自己的权限。

## 选择语言

Orbi Cloud 有英文和中文两个版本。首次访问时页面跟随你浏览器的首选语言，所以它可能以中文打开。

用右上角的旗标切换：🇬🇧 是英文，🇨🇳 是中文。你的选择存在 cookie 里，在那个浏览器上记一年。

## 个人账号和组织账号

如果你把 Orbi GitHub App 装在一个**组织**上而不是你的个人账号上，这个组织会拿到自己的 Orbi 租户 —— 它的仓库、它的订阅、它的用量都和你个人的那份分开记。

两种情况下登录方式都一样。你当前操作的是哪个租户，取决于你是从哪个安装进来的，所以当你同时拥有个人和组织两个安装时，从你想操作的那个租户对应的安装进来。

## 退出登录

**退出登录** (Sign out) 按钮在状态页底部的**账户** (Account) 卡片里。

<Frame caption="退出登录后的确认页">
  <img src="/images/signed-out.png" alt="退出登录后的确认页" />
</Frame>

退出登录只清掉那台设备上的会话。它不会卸载 GitHub App，不会取消订阅，也不会停掉一个已经在跑的交付。

## 会话过期时

一个会话持续 **7 天**，不会因为你一直在用而延长，所以你大概每周登录一次。如果你的已经过期，页面会写 **GitHub 登录已过期**，并给出**重新登录**；需要身份的页面会明说，而不是默默失败。

重新登录之后一切都还在 —— 你的仓库绑定、模型配置和交付历史都存在租户上，不存在浏览器会话上。
