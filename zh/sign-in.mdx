登录就是点一次 GitHub OAuth 确认你是谁，它本身不给 Orbi 任何仓库权限。

Orbi Cloud 没有自己的密码。你的 GitHub 账号就是你的身份，仓库权限是另一个独立、明确的步骤：[安装 GitHub App](/zh/install-app)，这一步由你在 GitHub 上控制。

## 登录

打开 **[orbi.build/api/](https://orbi.build/api/)**，点「使用 GitHub 登录」。

GitHub 会给你它标准的授权页。批准之后你会回到 Orbi Cloud：回到你本来要去的页面；如果还没装 App，就到一个带「安装 Orbi 的 GitHub App」按钮的页面。

登录只申请一个 OAuth scope，`user:email`：你的身份和你的邮箱地址，仅此而已。它不会给出任何仓库的代码或 Issue 的访问权限。那些来自 GitHub App 的安装，单独授权，也单独列出自己的权限。

<Note>
如果你是从 orbi.build 上的注册按钮进来的，而且从没装过这个 App，GitHub 可能会先给你看 App 的安装页，回来时顺带完成登录。结果是一样的：你登录了，App 也装在了你挑的那些仓库上。
</Note>

## 账户菜单

点 Orbi Cloud 页面右上角的 GitHub 头像。菜单提供网页语言、适用的订阅操作、「设置」、支持、使用文档和「退出登录」。

「设置」打开当前账户的统一设置页：

| 区域 | 控制什么 |
|---|---|
| 「AI 模型」 | provider、模型和 API key，见[模型配置](/zh/model-configuration) |
| 「Orbi 消息语言」 | Orbi 自己发的 GitHub 评论和 Telegram 消息的语言 |
| 「通知」 | 这个账户下所有仓库共用的 Telegram 机器人和接收目标，见[通知](/zh/notifications) |

能管理多个安装时，菜单会显示当前正在管理哪个安装，并提供切换入口。设置和用量属于选中的账户，编辑前先核对账户名。

## 选择语言

Orbi Cloud 有英文和中文两个版本。首次访问时页面跟随你浏览器的首选语言，所以它可能以中文打开。

在账户菜单里切换，或者用登录页右上角同样的 🇨🇳 ZH | 🇺🇸 EN 切换。你的选择存在 cookie 里，在那个浏览器上记一年。它只改变网页界面。GitHub 评论和 Telegram 消息的语言在「设置 → Orbi 消息语言」里另选，见[通知与消息语言](/zh/notifications#设置-orbi-的消息语言)。

## 个人账号和组织账号

如果你把 Orbi GitHub App 装在一个**组织**上而不是你的个人账号上，这个组织会拿到自己的 Orbi 租户：它的仓库、它的订阅、它的用量都和你个人的那份分开记。

两种情况下登录方式都一样。当你能访问不止一个安装时，用账户菜单里的「切换到 … 的安装」按钮选择要操作的租户。

## 退出登录

打开账户菜单，点「退出登录」。

退出登录只清掉那台设备上的会话。它不会卸载 GitHub App，不会取消订阅，也不会停掉一个已经在跑的任务。

## 会话过期时

一个会话持续 **7 天**，不会因为你一直在用而延长，所以你大概每周登录一次。如果会话背后的 GitHub 授权已经失效，状态页会显示「GitHub 登录已失效」，并给出「重新登录」按钮；需要身份的页面会明说，不会默默失败。

重新登录之后一切都还在：你连接的仓库、模型配置和任务记录都存在租户上，不存在浏览器会话上。
