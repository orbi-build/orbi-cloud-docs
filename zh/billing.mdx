订阅和取消都通过 Stripe 完成，入口在状态页的 **账户**（Account）卡片里。

Orbi Cloud 不保存你的卡信息。付款、发票和取消都由 Stripe 自己的托管页面处理。

## 套餐

| | |
|---|---|
| 免费额度 | **3 次合并的交付**，不用绑卡 |
| 之后的价格 | **79 美元/月** |
| 包含的模型用量 | **每个自然月 300,000,000 tokens** |
| 超额计费 | 没有 —— 到顶之后交付暂停，而不是继续计费 |

失败的交付不消耗免费额度。两种额度具体怎么计，见[额度与限制](/zh/limits-and-quotas)。

自托管开源的 [Orbi](https://orbi.build/?ref=cloud-docs-billing) 引擎是免费的，并且会一直免费。

## 订阅

在状态页的 **账户** 卡片里点 **订阅 Orbi Cloud**。你会被带到 Stripe Checkout，付款完成后回到 Orbi Cloud。

Stripe 确认付款之后订阅立即生效 —— 你不用做别的事，不用重新连接仓库，也不用重新配置任何东西。

<Note>
试用 Orbi Cloud 不需要先订阅。登录、安装 App、连接仓库、开通环境，以及你的前三次合并的交付，全都是免费的。
</Note>

## 管理订阅

订阅之后，**账户** 卡片里同一个位置变成 **管理订阅**。它打开 Stripe 的账单门户，你可以在那里更新支付方式、下载发票、取消订阅。

## 订阅状态

**账户** 卡片里的 **订阅状态** 一行告诉你现在处于什么状态：

| 显示的内容 | 含义 |
|---|---|
| **Founding Pilot** | 有一个生效中的付费订阅 |
| **订阅生效中** | 你的订阅状态正常 |
| **已降级（付款失败）** | Stripe 没能从你的支付方式扣款成功 |

如果你处于 **已降级（付款失败）**，在同一个账单门户里修支付方式 —— 这个门户在该状态下依然可达，就是为了让你能修。降级期间，派发逻辑把你的租户当成未订阅处理，所以新的 Issue 走免费额度的规则。

## 取消

在 Stripe 账单门户里取消。取消会停掉后续扣款；它不会删掉你的仓库连接、交付历史或模型配置。

取消之后，你的免费额度剩下多少就还剩多少 —— 也就是说，新的派发按[额度与限制](/zh/limits-and-quotas)里写的未订阅规则走。

要彻底移除 Orbi 对你代码的访问权限，去[卸载 GitHub App](/zh/install-app)。取消订阅和卸载 App 是两件独立的事。

## Founding Partner

前十个订阅者是 Founding Partner：订阅免费，每月 3 亿 tokens 照样包含，交换条件是每月提一张被接受的 Issue 来影响产品走向。优惠券数量有限，用完之后订阅就是 79 美元的正常价。

<Note>
**Founding Pilot** 和 **Founding Partner** 是两回事。Founding Pilot 是付费计划的名字，任何生效中的订阅在**订阅状态**那一行显示的都是它。Founding Partner 是这一节讲的计划，限前十个订阅者。
</Note>

## 发票和收据

所有发票都在 Stripe 账单门户的 **管理订阅** 里。Orbi Cloud 不会另外发邮件给你。
