你可以先免费试用 Orbi Cloud，之后在账户菜单里通过 Stripe 订阅 Solo 或 Pro。

Orbi Cloud 不保存你的卡信息。付款、发票和取消都由 Stripe 自己的托管页面处理。

## 套餐

| | 免费 | Solo | Pro |
|---|---|---|---|
| 你得到什么 | 前 **3 次合并的交付** | 月度额度内的交付 | 月度额度内的交付 |
| 包含的模型用量 | — | **每月 100,000,000 tokens** | **每月 300,000,000 tokens** |
| 同时绑定的仓库 | 1 | 1 | 最多 5 个 |
| 需要绑卡 | 否 | 是 | 是 |

两档付费套餐都可以按月或按年付，都没有按 token 的超额计费：当月额度用完后，新的交付会暂停，不会继续计费。当前价格、按年付的折扣和创始优惠都在 **[价格页](https://orbi.build/cloud/?ref=cloud-docs-billing)** 上，实际扣多少钱以它为准。

失败的交付不消耗免费额度，任何套餐都可以用你自己的模型 key。每种额度具体怎么计，见[额度与限制](/zh/limits-and-quotas)。

**选哪个套餐？** Solo 适合一个仓库、Issue 稳定地一张张来。想同时绑定多个仓库，或者 Solo 的月度额度撑不到月底，就选 Pro。

自托管开源的 [Orbi](https://orbi.build/?ref=cloud-docs-billing) 引擎是免费的，并且会一直免费。

## 订阅

有两个入口：

- **从价格页。** 在 [orbi.build/cloud](https://orbi.build/cloud/?ref=cloud-docs-billing) 上选 Solo 或 Pro、按月或按年。如果你还没登录，会先用 GitHub 登录；你的选择会被保留，在你完成订阅之前，账户菜单里一直显示 **你在价格页选了 …，继续订阅**。
- **从账户菜单。** 点你的头像，再点 **订阅 Orbi Cloud**。这个入口订阅的是按月付的 Pro；想要 Solo 或按年付，走价格页。

两种方式都在 Stripe Checkout 上完成付款，你也可以在那里填优惠码，付完之后 Stripe 会把你带回 Orbi Cloud。

Stripe 确认付款后订阅立即生效。账户菜单显示 **订阅已生效**，你的套餐名出现在登录名旁边。你不用重新连接仓库，也不用重新配置任何东西。

<Note>
试用 Orbi Cloud 不需要先订阅。登录、安装 App、连接仓库、开通环境，以及你的前三次合并的交付，全都是免费的。
</Note>

## 管理订阅

订阅之后，账户菜单里对应的位置变成 **管理订阅**。它打开 Stripe 的账单门户，你可以在那里更新支付方式、下载发票、取消订阅。

在 Solo 上，月度额度用完时状态页还会直接提供 **升级到 Pro**，见[额度与限制](/zh/limits-and-quotas)。

## 订阅状态

账户菜单里登录名旁边的标签显示你的套餐：

| 显示的内容 | 含义 |
|---|---|
| **未订阅** | 在用免费额度 |
| **Solo** 或 **Pro** | 该套餐下有一个生效中的付费订阅 |
| **Founding Pilot** 或 **Design Partner** | 来自早期访问计划的生效中订阅 |
| **已降级（付款失败）** | Stripe 没能从你的支付方式扣款成功 |

如果你处于 **已降级（付款失败）**，就在同一个账单门户里修支付方式。这个状态下 **管理订阅** 依然可用，就是为了让你能修。降级期间，派发逻辑把你的账户当成未订阅处理，所以新的 Issue 走免费额度的规则。

## 取消

在 Stripe 账单门户里取消。取消会停掉后续扣款；它不会删掉你的仓库连接、交付记录或模型配置。

取消之后，新的派发按[额度与限制](/zh/limits-and-quotas)里写的未订阅规则走。

要彻底移除 Orbi 对你代码的访问权限，去[卸载 GitHub App](/zh/install-app)。取消订阅和卸载 App 是两件独立的事。

## 发票和收据

所有发票都在 **管理订阅** 打开的 Stripe 账单门户里。Orbi Cloud 不会另外发邮件给你。

## 对某笔扣款有疑问

付费和退款的问题发到 **support@orbi.build**，见[获取帮助](/zh/troubleshooting)。
