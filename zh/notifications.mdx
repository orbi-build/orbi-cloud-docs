点右上角头像，进入「设置」，找到「通知」。一份配置覆盖页面顶部所示账户下的所有仓库；切换个人账户或组织后，编辑的是切换后账户的设置。

你需要创建一个 Telegram 机器人，并选一个私聊或群接收消息。不需要在本地安装或运维 runner。

## 什么时候会收到消息

| 事件 | 消息告诉你什么 |
|---|---|
| 任务停在 `ai-blocked` | 哪张 Issue 需要你决定；重新派发前先读 Orbi 的评论 |
| 需求待补充（`ai-needs-detail`） | 哪个需求还缺信息；按提示[补充需求](/zh/troubleshooting#orbi-需要更多信息) |
| 检查通过的 PR 等合并（`ai-awaiting-merge`） | 哪个 PR 在等你批准或合并 |
| 交付检查单需要你确认 | Orbi 在等你检查；到 Issue 上看检查单 |
| Orbi 开的 PR 已合并 | 哪次改动已经合并，包括由人手动合并的情况 |

Orbi 自己完成这些状态变化时才会提醒；手动补一个标签不会补发过去的通知。这些消息提醒你处理任务结果和决策，不会逐条播报执行过程。在 Telegram 回复机器人不会纠正交付方向；请在 [GitHub Issue 上补充或纠正](/zh/delivery-lifecycle#让正在跑的交付转向)。

通知失败不会让任务失败，也不会改变任务标签。查看交付结果仍然用 GitHub 和[状态页](/zh/status-page)。

## 配置通知

1. **创建机器人**：在 Telegram 打开 [@BotFather](https://t.me/BotFather)，发送 `/newbot`，按提示命名。把它返回的 token 粘到 Orbi 设置里的「Bot token」。
2. **和机器人打个招呼**：打开刚建的机器人，点「开始」或发送 `/start`。要发到群里，就把机器人加入群，允许它发言，并在群里发送 `/start@机器人用户名`，把用户名换成你自己的。
3. **选接收消息的会话**：点「获取 Chat ID」，从列表选私聊或群，Orbi 会填入「Chat ID」。也可以自己填已知的 ID；群号前面的负号要保留。
4. **验证并保存**：Orbi 先向 Telegram 核对 token 和会话，没通过就不改原设置。首次保存成功后通知会开启，并请求发送一条测试消息。

到 Telegram 确认实际收到测试消息，通常需要 **1–2 分钟**。保存成功本身不能证明消息已经送到。之后修改配置，一般 **1–10 分钟**生效。

群成员可以看到消息里的任务标题和链接。选择目标时要考虑这个账户下的所有仓库，包括私有仓。不要把 bot token 贴进 Issue、截图或求助消息；保存后 Orbi 只显示掩码。以后只改 Chat ID 时，「Bot token」留空就沿用已保存的 token。

## 测试、关闭与删除

保存后，这一段会显示「已开启」和保存的接收目标，或「已关闭」及配置已保留的说明。

- 「发送测试消息」只请求发送一条测试，不会保存输入框里尚未保存的修改；需要先开启通知。
- 「关闭通知」保留配置，变更生效后停止发送新通知。「开启通知」会重新启用，并请求一条测试消息。
- 「删除配置」会先让你确认。确认后清空通知配置，再用时需要重新填写 token 和 Chat ID；它和关闭通知是两个动作。

只编辑输入框不会改变当前接收目标，要点「验证并保存」才会应用。通知关闭时保存修改，仍保持关闭；点「开启通知」才会开始接收。

## 设置 Orbi 的消息语言

同一个「设置」页里，找到「Orbi 消息语言」，选「中文」或「English」，点「保存」。它控制这个账户下 Orbi 自己发的 GitHub 评论和 Telegram 消息；尚未保存选择时默认用英文。

网页界面的语言另在头像菜单切换。把网站切成中文，不会同时把交付消息改成中文。这个设置也不会翻译你的 Issue 正文、标题或代码。仓库显式设置了 `message_language` 时，该仓库的 GitHub 评论采用仓库设置；Telegram 仍采用账户的语言，见引擎的[评论语言说明](https://docs.orbi.build/zh/workflow#评论语言)。

## 配置失败或没收到消息

| 遇到什么 | 怎么处理 |
|---|---|
| 没找到会话 | 向自己的机器人发 `/start`，或在群里发 `/start@机器人用户名`，再点「获取 Chat ID」 |
| 机器人已由其他服务接管 | 创建专用机器人，或手动填写已知的 Chat ID |
| Bot token 无效 | 回 BotFather 复制完整 token，重新保存 |
| Telegram 找不到会话 | 核对机器人是否收到 `/start`、是否在群里且能发言，并保留群号前面的负号 |
| Telegram 限流、不可用或响应超时 | 稍后重试；验证失败不会覆盖原来的设置 |
| 保存了，但没收到测试消息 | 等 1–2 分钟，核对已保存的 Chat ID 和机器人能否访问会话，再请求测试 |

仍收不到就[联系支持](/zh/troubleshooting#怎么找人)，提供账户、仓库、Issue 链接和大致时间，不要附 bot token。
