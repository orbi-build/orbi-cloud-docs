你不需要配置模型，免费交付和两档付费套餐都含模型用量。如果你更愿意直接付钱给 provider，或者希望付费套餐的月度额度用完后交付不停，可以用自己的 key。

默认情况下，交付跑在 Orbi 的平台模型通道上。所以你可以一个 key 都不填就完成安装、连接仓库、走完一次交付。

配置自己的 key，也就是 **BYOK**（bring your own key），会给你的账户加上一个你自己的 provider 账号作为模型来源。交付用哪个来源，取决于你的套餐：

- **免费账户**：保存 key 之后，交付就用你的 key。
- **付费账户**：交付先用套餐里包含的月度额度；额度用完后改用你的 key，不会暂停。

## 什么时候该配 key

| 情况 | 该做什么 |
|---|---|
| 你只想让它跑起来 | 什么都不用做，平台通道会自动使用 |
| 你想用某个特定模型，或者你的合规要求必须走自己的 provider 账号 | 配 BYOK。付费账户要等月度额度用完后才会改用你的 key |
| 你已经用完月度 token 额度 | 配 BYOK。保存之后交付立即恢复，你自己的 key 永远不会因为额度被暂停 |

## 怎么配

在 Orbi Cloud 任意页面点右上角的头像，选「AI 模型设置」，打开的页面标题是「模型配置」。本月额度用完时，状态页上的「改用自己的 API key」也会链到这里。

  <img src="/images/zh/model-config.png" alt="模型配置页面，包含 provider、baseUrl、model_id 和 apiKey 字段" />
</Frame>

1. 「provider」：从列表里选。选中之后 base URL 会自动填好。
2. 「baseUrl」：自动填好，可以改。只有在你用代理或私有网关时才需要改。
3. 「model_id」：从该 provider 的已知模型里选，或者选「手填其他模型」，输入列表里没有的 model ID。
4. 「apiKey」：你在那个 provider 处的 API key。

想先检查这组配置能不能用，就点「测试连接」：它用你填的内容发一个小请求，结果要么是「连接成功」，附上模型和耗时，要么是 provider 返回的报错。然后点「保存模型配置」。

保存时会先跑一遍同样的连接测试，测试不通过就什么都不存：页面显示报错，保留你填的内容，并提示「为安全起见需要重新输入 API key。」不在内置列表里的 provider 没法这样测试，会按你填的原样保存。

保存成功后页面会提示「模型配置已保存」。保存之后生效的是后续开始的交付。如果之前因为凭据不对，工作环境准备失败过，保存一份改好的配置会自动重试。

## 你的 key 怎么存

你的 API key 静态加密存储，回显给你时永远是掩码，字段标签显示的是类似「apiKey（当前：••••1234）」的样子，从不显示 key 本身。它不会写进日志，不会进支持用的证据包，也不会出现在任何可能被分享出去的界面里。

<Frame caption="已保存的配置：不在内置列表里的 provider 按原值保留，已保存的模型，key 以掩码显示">
  <img src="/images/zh/model-config-set.png" alt="已保存的配置：不在内置列表里的 provider 按原值保留，已保存的模型，key 以掩码显示" />

不要用邮件发你的 key，也不要粘进 GitHub Issue、pull request 或评论。就在这个页面上填，你只需要这一个通道。

<Note>
列在这里的 provider，不等于承诺你的账号在它上面对某个模型有额度、有访问权限或者有足够的速率限制。如果你的 key 拿不到某个模型，连接测试会失败，或者交付会带着 provider 自己的报错失败。
</Note>

## 用列表里没有的 provider

随便选一个 provider 当起点，然后把「baseUrl」改成你网关的 URL，用「手填其他模型」输入 model ID。任何 OpenAI 兼容的端点都能用。保存时照样会对你填的 URL 跑连接测试。你的配置按你填的原样存下来，回显时也不做改动。

已保存的 provider 如果不在内置列表里，会像上面截图那样带着「（不在内置 provider 列表，按原值保存）」显示；已保存的模型如果不在该 provider 的列表里，会带着「（已保存）」显示。

## 移除你的 key

模型配置页上没有删除按钮。想只用平台通道，请[联系我们](/zh/troubleshooting)移除你的 key。想换一个 key，直接保存新的覆盖旧的就行。

## 用 BYOK 之后有什么变化

| | 平台通道（默认） | 你自己的 key |
|---|---|---|
| 谁付 token 的钱 | 套餐里包含 | 你付给你的 provider |
| 什么时候用 | 免费账户：没保存 key 时。付费账户：月度额度用完之前 | 免费账户：每次交付。付费账户：月度额度用完之后 |
| 月度 token 额度 | 付费账户按套餐额度（Solo 400,000,000，Pro 1,200,000,000） | 不适用：用量照样统计，但永不暂停 |
| 模型选择 | 由 Orbi 运维 | 你自己定 |
| 状态页上的用量 | 「本月 AI 用量」，付费账户对照额度显示 | 「本月 AI 用量（你的 API key）」，单独一行、没有上限，你的 key 用过之后才出现 |

额度怎么计，见[额度与限制](/zh/limits-and-quotas)。
