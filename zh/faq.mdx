高频问题的简短回答，展开说明在链接里。

## 开始用

**试用之前必须付费吗？**
不用。登录、安装 App、连接仓库、开通环境，以及前 **3 次合并的交付**全部免费，不用绑卡。见[计费](/zh/billing)。

**必须配置模型或 API key 吗？**
不用。订阅本身包含每月 3 亿 tokens，交付默认走平台通道。配置自己的 key 是可选项 —— 见[模型配置](/zh/model-configuration)。

**需要在本地装什么吗？**
不用。全程在浏览器和 GitHub 里完成。你不会拿到 runner 的 shell，本地也不跑任何东西。

**可以用在私有仓库上吗？**
可以。GitHub App 在你授权的私有仓库上正常工作。

**能连多个仓库吗？**
目前不行 —— 同一时间一个生效仓库。没有交付在途时可以随时换。见[连接仓库](/zh/connect-repository)。

**能用在组织的仓库上吗？**
可以。把 App 装在组织上，会为这个组织创建一个独立的租户，有自己的订阅和用量。

## 跑交付

**怎么把活交给 Orbi？**
在连接的仓库里建 Issue 并打上 `ai-ready` 标签 —— 或者用状态页上的**让 Orbi 试这张**。见[派发第一张 Issue](/zh/first-issue)。

**多久开始？**
最长 5 分钟。认领走定时器，不是即时触发。

**一次交付要多久？**
完全取决于任务大小。小而具体的改动很快，大而模糊的会慢，并且会走更多修复轮次。

**跑到一半我改主意了怎么办？**
在 Issue 上评论或编辑正文 —— 正在跑的会话会带着你的修正重启。它接受 3 次这样的重启，且只有仓库的可信角色能转向。见[交付生命周期](/zh/delivery-lifecycle)。

**能中止一次交付吗？**
关掉 Issue。如果那是未订阅状态下且未合并的交付，关闭会把免费名额退回来。

**Orbi 是自己评审自己的代码吗？**
评审跑在一个**没有写过这份代码**的会话里，它会先修掉发现的问题，之后才可能进入合并门禁。这不是同一个会话给自己判卷 —— 但它仍然是 Orbi，所以真正让保证落地的是你自己的 CI。

**它会不经我批准就合并吗？**
会 —— 在评审结论干净且合并门禁通过时，这正是无人值守循环的意义。如果你希望每次交付都要人工批准，把分支保护设成要求 approving review；见[安全](/zh/security)。

**`ai-blocked` 是什么意思？**
是有意的停止，表示需要人来决定下一步，不是崩溃。修掉原因，然后重新打 `ai-ready`。见[问题排查](/zh/troubleshooting)。

## 额度与价格

**多少钱？**
3 次合并的交付免费，之后 79 美元/月，含 3 亿 tokens。没有按 token 的超额计费 —— 额度用完时交付暂停。见[计费](/zh/billing)。

**失败的交付会消耗免费额度吗？**
不会。落到 `ai-blocked` 或未合并就关闭的交付会把名额退回来。

**3 亿 tokens 能跑多少次交付？**
大约 85 到 400 次合并的交付，取决于任务大小，前提是你的 provider 支持 prompt caching。

**月额度用完会怎样？**
新打标签的 Issue 会被摘掉 `ai-ready` 并附一条说明评论。在途交付不受影响。等下个月或改用自己的 key，然后**自己重新打标签**。见[额度与限制](/zh/limits-and-quotas)。

**额度掉得很快，为什么？**
看状态页的缓存命中率。缓存未命中的 token 单价约为命中的 50 倍，低于 90% 会明显更快烧额度。

## 发版

**Orbi 会自动发版吗？**
永远不会。你在**发个版本**里填版本号，或者自己开一张带 `ai-release` 标签的 Release Issue。见[发版](/zh/releases)。

**版本号是它决定的吗？**
不是，你填。下一个版本发什么是产品决策，Orbi 不替你做。

**发版为什么停在 scope 推导？**
scope 来自标题与版本号完全一致的 milestone。Orbi 不会替你创建这个 milestone。

## 安全与权限

**Orbi 能看到什么？**
只有你 GitHub App 安装范围内的仓库，并且只在你连接的那一个仓库里工作。见[安全](/zh/security)。

**我的 API key 存在哪？**
以 AES-256-GCM 加密存储，回显只显示掩码，永远不写日志。

**怎么撤销访问？**
从 GitHub 卸载 GitHub App，访问权立即终止。取消订阅是另一件事，要单独做。

**平台升级会打断我的交付吗？**
不会。部署在结构上就不可能重启一个正在执行的交付。

## 产品

**这和自托管的 Orbi 是一回事吗？**
交付引擎是同一套，区别在于谁运维 runner。引擎开源，自托管永久免费 —— [orbi.build](https://orbi.build/?ref=cloud-docs-faq)。

**稳定吗？**
Orbi Cloud 处于 Private Beta。本文档描述的是当前已上线的形态，不是路线图。

**去哪找人？**
状态页底部**技术支持**卡片里的 Telegram 群，带二维码。见[问题排查](/zh/troubleshooting)。
